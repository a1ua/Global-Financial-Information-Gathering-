# Batch08-C 高水位与审计信任决策

2026-11-09。当前仓库没有已验收的独立单调状态服务、外部签名锚点或受控不可回退存储，也没有供应商逐调用凭证关联。项目本轮采用明确可运行的本地追加审计；其信任级别local_untrusted_audit，不具备生产恢复切换条件。

本地SQLite审计独立于模型工作区，触发器保护普通写接口，链哈希和序号发现部分损坏；可保留重复观察及跨账本事件顺序。把文件移到工作区之外仅减少误恢复混用，不赋予独立访问控制、单调持久性或来源认证。完整旧链可自洽，重算全链也可能自洽。

因此本轮不添加可返回trusted_high_water=true的后端、不添加verified/applied事件或费用释放，不撤销既有恢复预检blockers。审计库损坏/不可用时audit-record失败，不修改模型账本；现有只读预检仍可运行，其禁止结算/切换语义不变。审计库本身如何安全备份/导出及与未来可信锚点耦合，需另立工作包，本轮不自动当作已备份。

后续在实际部署环境中先选定受独立权限保护的单调持久边界及操作者，再验证：已提交高水位不丢失；重复写幂等、并发推进和冲突拒绝；旧值/断链/换身份拒绝；不可用时失败关闭；账本与外部状态中断恢复；供应商请求关联及凭证真实来源。外部服务账号、凭证、费用与部署尚无实际输入，不能以普通文件或本地模拟替代这一验收。
