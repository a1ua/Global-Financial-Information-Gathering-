日期 2026-11-20。审查范围为固定上交所会话日期、离线指数日线样本、覆盖与哈希报告，以及 CLI 的读取和退出状态。

实现按明确的 `.SH` 代码及同年日期窗口选取预定会话。无预定日期、倒序或跨年窗口均被拒绝。保留窗口外样本行以便报告意外日期，保留重复以便报告重复日期。响应哈希绑定原始字节，日历哈希沿用固定快照。代码后缀只约束输入范围，实际映射仍待来源验收。

使用项目 Python 3.12.14 执行 `test_market_sample_audit`、`test_market_sample`、`test_scheduled_sessions`、`test_tushare_sample`，23 项通过，退出码 0。另在独立进程运行四组定向场景，退出码 0。

1. 固定日历哈希与独立 SHA-256 运算一致。增加 JSON 前导空白仅改变响应哈希。检查报告不含行内价格值，同时保留窗口外的开市日和休市日。
2. 七种非法范围或代码被拒绝，错误为 `sse_index_sample_scope_invalid`。覆盖周日期、紧凑日期、跨年、倒序、纯休市范围及异市场后缀。
3. CLI 与 Python 返回同一报告。完整退出 0，缺失或意外或重复退出 2。用桩禁止 socket 和 SQLite 创建，两个输入文件的内容和目录清单均保持原样。
4. 用超长文件、重复日历键及带私有标记的供应商错误测试退出 1，错误未包含输入路径或供应商消息。初次检查误将诊断报告的预期退出码设为 0，改正后四组复跑均通过。

本记录覆盖合成样本及公开公告生成的计划日期。真实供应商样本、实际会话与价格时点由来源验收处理。独立检查没有使用 Antigravity 或全量测试计数。
