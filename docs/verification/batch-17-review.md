## 独立行为检查

使用桌面内置 Python 3.12.14 和 SQLite 临时目录运行 7 组自构造场景，两次执行均退出 0。

1. 时钟回调内使用另一连接，观察到内容及关联已提交，判断读取仍返回空。回执提交后正式读取成功。同输入重试返回同一回执，未再次调用时钟。
2. 同一日历 ID 配不同快照哈希的更正被拒绝。更正时间早于前驱回执时，内容保留为无回执行。
3. 拒绝已有调用方事务且保留事务状态。在关闭递归触发器时，判断、证据引用及回执三表仍拒绝 `INSERT OR REPLACE`。
4. 备份恢复到新目录后，原回执与无回执行均保留。只在恢复后的副本补回执，源库仍无该回执。
5. 修改备份的回执时间到创建时间之前，恢复原修改保护触发器，再重新计算数据库文件哈希并更新清单。备份验证仍拒绝该时间，单独验证了行语义检查。
6. Python 3.12 的显式 autocommit 连接正确提交两段事务。三表采用 `WITHOUT ROWID`，`SELECT rowid` 和指定 rowid 的替换均被拒绝。
7. 篡改原文文件后，相同输入的提交重试因证据失效而被拒绝，已存回执保持原样。`read_prediction` 是既有记录检索，调用时不重开原文文件。提交和备份阶段校验原文字节。
