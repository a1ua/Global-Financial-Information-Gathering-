## 实施前设计审查

预期交易日由调用方提供，校验器按严格升序、唯一的 ISO 日期接受最多 366 个会话。日线价格采用正十进制字符串和精确比较，最高、最低须同时限定开盘和收盘。缺少、意外和重复日期逐类统计，可同时出现。任何日线行的格式或价格区间非法时拒绝整个样本，包括意外交易日上的记录。该检查适用于离线样本结构与覆盖，来源适用性由提供方口径、时点与授权证据另行判断。设计通过。

## 运行核验

使用桌面内置 Python 3.12.14，关闭字节码写入，从工作区 src 与 tests 执行独立脚本及 test_market_sample 模块。7 项定向测试全通过，耗时 0.006 秒。独立脚本通过 4 组补充场景。

- 50 个固定种子的合成交易日样本逐项核对缺失、意外、重复、计数、状态和原输入保持。
- 在 Decimal 精度设为 2 时，12 位整数与 8 位小数仍精确判定收盘价是否超出上界。
- 非法月末、附加时间、尾部换行和非 ASCII 数字分别在两端日期字段被拒绝。
- 意外日期或重复日期出现非法日线时，固定错误码终止处理。

结构检查和用例通过。
